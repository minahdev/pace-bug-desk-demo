PACE 버그 제보 데스크

건강 앱 PACE에 들어온 버그 제보를 Claude Haiku 5.5가 읽고 분류해서, 이미 알려진 이슈와 연결하고 얼마나 급한지 알려 주는 서비스예요.

이 사이트는 데모예요. 진짜 서비스가 예시 제보 8개를 분석한 결과를 그대로 보여 줘요. 새 글을 직접 넣어 분석하려면 GitHub의 코드를 받아 내 컴퓨터에서 실행하면 돼요.

예시 제보 고르기

어떻게 동작하나요

  1. 분류 (Haiku): 버그 · 문의 · 개선 요청 · 판단 불가 중 하나를 고르고 이유를 써요.
  2. 정보 뽑기 (Haiku): 플랫폼, 기기, 앱 버전, 재현 절차를 글에 있는 것만 뽑아요.
  3. 이슈 연결 (Haiku + 도구): 기록부를 검색해서 같은 문제를 찾고 심각도를 매겨요.
  4. 점수 계산 (코드): 우선순위 = 심각도 + 영향 범위 + 해결 상태. 빈칸은 사용자에게 물어볼 질문이 돼요.

2와 3은 1의 결과를 받아 동시에 처리해요. 글의 뜻을 판단하는 일은 Haiku가, 같은 입력에 늘 같은 점수가 나와야 하는 계산은 코드가 맡아요.
